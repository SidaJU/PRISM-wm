高斯分布与采样：z = mu + std × 噪声

PRISM-WM 笔记 13 · 图解 posterior/prior 输出的"分布"以及 z 是怎么采出来的

一句话：网络输出的不是 z，而是一个高斯分布（mu 中心 + std 宽度）； z = mu + std × 噪声 是从这个分布里随机抽一个点作为本次实际使用的状态。

1先看清：网络输出什么

post = self.post_net(...)                    # 输出 64 维
mu, logvar = post.chunk(2, dim=-1)           # 拆成 mu(32) + logvar(32)
std = (0.5 * logvar).exp()                   # logvar → 标准差 σ
z = mu + std * torch.randn_like(std)         # 采样出 z(32)
量符号含义UE 类比
muμ分布中心（最可能的值）目标最可能的位置
logvarlog(σ²)对数方差（网络实际输出的）误差半径的对数
stdσ标准差（不确定度）误差半径
z—采样出的一个具体值实际射中的位置

2高斯分布长什么样

钟形曲线：mu 是峰顶（中心），σ 决定"胖瘦"；±1σ 内约 68%，±2σ 内约 95%

为什么输出 logvar 而不是 σ？

做法问题
直接输出 σ²（方差）可能为负 → 非法 ❌
输出 |σ|（绝对值）0 处不可导，梯度有问题 ❌
套 softplus接近 0 时梯度饱和，不如 exp 稳
输出 log(σ²)✅ 任意实数都合法，exp 后自动为正；数值稳、梯度平滑

三者换算（数值例子）

logvar方差 σ² = exp(logvar)标准差 σ = exp(0.5·logvar)含义
−4.00.0180.135很确定（窄）
−2.00.1350.368中等
0.01.0001.000标准正态
+2.07.3892.718很不确定（宽）

3核心：采样公式在做什么

z = mu + std * torch.randn_like(std)

把它拆成三步理解：

步骤操作说明
①randn_like(std)生成一组标准正态随机数（均值 0、标准差 1），形状和 std 一样（32 维）
②std * 噪声把噪声放大/缩小到模型想要的不确定度（std=0.1 → 抖动很小；std=2 → 抖动很大）
③mu + ...把抖动平移到分布中心 mu 附近 → 得到本次实际使用的 z
采样 = 标准噪声 × 不确定度(std) + 中心(mu) → 本次落点 z

torch.randn_like(std) 到底是什么

部分含义
torch.randnrandom normal —— 生成标准正态分布（均值 0、标准差 1）的随机数
_like(std)生成结果的形状和 std 完全一样（不用手写维度）

一句话：返回一个和 std 同形状的张量，每个元素独立从 N(0, 1) 里随机抽一个值。

真实输出（8 维示例，实测）

std   shape : (1, 8)
noise shape : (1, 8)                                  ← 自动匹配
noise 值    : [1.541, -0.293, -2.179, 0.568,
              -1.085, -1.399, 0.403, 0.838]
noise 均值  : -0.201   （应接近 0）
noise 标准差 :  1.265   （应接近 1，样本少所以有偏差）
有负数吗    : True      ← 高斯的特点：可正可负

别搞混：randn_like vs rand_like

函数分布取值范围实测值
randn_like正态（高斯）可正可负，集中在 0 附近（±1 内约 68%）1.541, -0.293, -2.179, ...
rand_like均匀只有 0~1 的正数0.698, 0.800, 0.161, ...
为什么必须是 randn，不能用 rand？
采样公式 z = mu + std × 噪声 的数学前提是噪声 ~ N(0,1) —— 只有这样，算出来的 z 才服从正确的分布 N(mu, std²)。
换成均匀噪声（rand），z 的分布就错了，模型的概率假设被破坏，训练与采样都会偏。

公式里的三个角色

z = mu  +  std  ×  randn_like(std)
    ↑       ↑        ↑
   中心    幅度     随机方向
   靶心   放大镜     掷骰子的结果
  • 噪声：提供随机性（往左偏还是往右偏）
  • std：控制偏多远（std=0.1 → 几乎不动；std=2 → 大幅偏离）
  • mu：决定基准位置

两个实用细节

  • _like 的好处：自动匹配形状。我们的 std 是 (B, 32)，噪声也是 (B, 32) —— 改 batch 或 latent 维度时不用改这行代码。
  • 每次调用都重新随机：所以 sample=True 时同一模型跑两次结果会略有不同； 需要可复现结果时用 sample=False（直接用 mu）或固定随机种子。

4手算一个 2 维例子

量维 0维 1
mu（中心）1.0−0.5
logvar−2.00.0
→ std = exp(0.5·logvar)0.36791.0
随机噪声（randn 抽到的）+0.5−1.2
→ 偏移量 std × 噪声0.3679 × 0.5 = +0.1841.0 × (−1.2) = −1.2
z = mu + 偏移1.184−1.700
怎么读这个结果：维 0 的 std 小（0.368）→ z 只偏离 mu 一点点（1.0 → 1.184， "比较确定"）；维 1 的 std 大（1.0）→ z 偏离很多（−0.5 → −1.7，"没把握"）。 32 维各自独立，每维有自己的 mu 和 std。

5图解：采样本次"落在哪"

同一个分布采 6 次：std 小 → 点都挤在 mu 附近；std 大 → 点散得很开
关键理解：每次调用 imagine()（sample=True）， 噪声都是重新随机生成的 → 同一个模型跑两次，z 会略有不同 → 结果不完全一致。 这就是为什么我们做评测时会用 sample=False（直接用 mu）来获得可复现的结果。

6为什么写成这个形式（重参数化）

直接"从分布里采样"这个动作不可导——梯度传不过去，模型就没法训练。

直接采样:   z ~ N(mu, std)          ← 不可导 ❌
重参数化:   z = mu + std * 噪声      ← 噪声是常数，梯度可顺着 mu / std 回传 ✅
写成 mu + std × 噪声 后，随机数变成"常数"， mu 和 std 仍在网络里 → 梯度正常回传 → 这就是重参数化技巧（VAE 的核心）。

7回到模型：z 用在哪

114  z = self._rsample(mu_q, lv_q)      # 训练/observe：从 posterior 采（看过图）

一句话串起来：posterior/prior 输出一个分布（mu + std）， 从里面采样一次得到 z，z 与记忆 h 拼起来交给下游预测头—— z 是"对当前世界状态的一次带不确定性的判断"。
