2v1：训飞的条件与现象

当时的条件

  • 训练数据：1,241 局（旧采集版）。事后分析发现三个问题：
    1. 79% 的 episode 方块被推下桌面——掉落后仍继续采集，大量"方块躺在地上"的垃圾帧
    2. 画面几乎静止：相邻帧差异仅 0.0026（机械臂移动慢 + 64×64 透视压缩）
    3. 方块与桌面同色（灰对灰），64×64 下不可见——模型从画面里"看不到"方块
  • KL 塌缩已被 free_bits 修复（KL 0.000002 → 0.032），训练指标全部正常
  • 训练 loss 收敛看起来没问题——问题隐藏在"长程推演"里，训练时根本测不到

3排查：怎么定位到"数据"的

  1. 假设 A：prior 采样噪声 → 加 sample/mu 双模式开关实验 → 两条曲线几乎重合 → 否定（采样噪声只是小头）
  2. 假设 B：decoder 对 emb 漂移敏感 → 图上噪点从"大面积均匀区域（桌面）"开始、 恒定背景不坏 → 支持：emb 漂出训练分布后，decoder 在见过的模式间随机跳变
  3. 追问：为什么 emb 会漂？为什么 decoder 这么脆？ → 回到数据： 静止帧污染 + 运动信号弱 + 方块不可见 → 模型只学到"特定输入→特定画面"的窄映射， 没有学到可纠错的动力学
  4. 决定性验证：只换数据（重采 743 局）、其余全部不变 → v2 修复 → 证实数据是主因
排查工具：sample/mu 双模式开关（一行代码）、逐帧误差热图、 render 一致性验证（相机参数）、val/train 分离检查。

④ 澄清：imagine 的参数没改过

v2 没有动 imagine 的任何算法参数 —— context=8、horizon=20 始终是 8 和 20。 变化的是它读的数据和用的权重：

读 prism/data/L0 → 取验证集第一局 → 前 8 帧 observe 建立记忆 → 想象 20 步
                        ↑ 由旧 1241 局换成重采的 743 局（模型也换成重训后的权重）

所以那"8 帧"是新数据集里的新序列，不是把 context 从别的值改成 8。

7当前状态：loss 分析与 free_bits 对照实验

① 训练 loss 的量级失衡（关键发现）

用 eval_curve.py 测"真实 KL"（调用 loss 时不带 free_bits，不受地板掩盖）：

分量ep20 真实值说明
kl(真实)0.020占总 loss 约 95% —— 绝对主导项
recon0.0006比 KL 小 30 倍
emb0.00004比 KL 小 500 倍（早期就饱和到 1e-5，不再提供梯度）
proprio0.00003同上，早饱和
两个"陷阱"： ① 训练日志里 kl 恒为 0.10000 是假象 —— 真实 KL 只有 0.02~0.067（被地板 0.1 顶住显示）； ② 看总 loss 没有意义（它≈KL 常数），判断训练进展要看 recon/emb/proprio 分量。

② free_bits 对照实验（只改这一个参数）

出于"KL 项梯度被地板吃掉、prior 没被训练"的假设，做了 free_bits 0.1 → 0.01 的重训对照：

free_bits真实 KL训练总 lossval_loss第20步想象 MSE结论
0.10.0200.10070.019~0.079（波动）0.0049 ✅✅ 更好
0.010.0060.01060.005~0.008（更稳）0.0509 ❌❌ 更差
阴性结果：降低 free_bits 确实让 KL 恢复梯度（val_loss 更低更稳：0.005~0.008）， 但真实 KL 被压到 0.006 → z 承载的信息减少 → 长程想象反而退化（0.0049 → 0.0509，差 10 倍）。
结论与决策：KL 不是越低越好 —— 需要保留一定的 KL（z 有信息）才能想象得好。 已 revert 回 free_bits=0.1，并在 config 里注明"勿再调低"。

③ 当前"看起来好"的指标与真实问题

指标表现可信度
训练收敛（recon↓、KL 稳）✅ 好可信
像素 MSE（imagine 20 步 0.0049）✅ 好⚠️ 对"物体动力学"是盲的 —— 方块仅 1px，位置误差被背景淹没（见下）
物体动力学（方块会往哪走）❌ 没学到真实缺陷（观察：真实物体动了 6cm，想象画面方块不动）
根本问题：方块在 64×64 里不到 1 个像素 → 它的运动在 loss 里几乎不贡献梯度 → 模型没有动力学学习信号。像素 MSE 无法衡量这一点，必须引入"物体位置误差"指标（v5）。

④ 下一步（按此顺序）

  1. v5：物体位置预测头（从 h,z 预测方块 xyz）+ 把"物体位置误差"作为评测指标 —— 让"难而重要"的梯度进来，也是唯一能验证"学会物体动力学"的尺子
  2. v3/v4：方块加大（2.5→4cm）+ 分辨率 64→96 —— 让物体在画面里可见
  3. 继续用 eval_curve.py 监控真实 KL（不被地板掩盖），警戒线：KL < 0.001 = 塌缩；KL < 0.01 = 信息过少（想象会退化）
